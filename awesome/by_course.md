# Awesome Computer Science By Course - UFPA

## Formal languages and automata theory

### Game of Life (Taygo & team)

Javascript implementation of Conway's Game of Life using free-context language.

Authors: @nathil, @ofranbraga, @murilo-henrique060, @nathil, @TaygoCezar.

[Github](https://github.com/nathil/Jogo-da-Vida).

### Arithmetic Python Interpreter (Arthur Smith & team)

A calculator with a web frontend interface and a Python backend.

Authors: @kmiepng, @Arthur-Negrao-Smith, @Itallo0708.

[Github](https://github.com/Arthur-Negrao-Smith/Interpretador-Aritmetico-Python).

### LFeAutomata (Dhario Newbery & João Davi)

An Automata and Formal Languages course assignment of textual pattern recognition using regular expressions. Implementation in Python.

Authors: @DharioNewbery and @JoaoDavi2302.

[Github](https://github.com/DharioNewbery/LFeAutomata).

### Regex in C (Mateus Barreto & Fabio Juan)

An Automata and Formal Languages course assignment of textual pattern recognition using regular expressions. Implementation in C using PCRE2.

Authors: @fabill_faaf and @seruna.

[Codeberg](https://codeberg.org/seruna/regex-automata-assigment).
